# Tiny chess engine

A 4 KB Python chess engine (3,557 bytes) for [make.fun](https://make.fun/bounty/tiny-chess-01)'s tiny-chess-01 bounty. PVS + root ordering, null-move pruning (R=2, zugzwang guard), check extension, precomputed PST eval. 100,000 nodes/move, deterministic, Python 3.13 stdlib only. Practice Elo 1,451.

Run: `python3 main.py`
